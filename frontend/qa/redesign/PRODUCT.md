# Exploratory apraxia front page

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

This isolated design study explores the personal apraxia home workspace. The user requested a mockup, not a final product, and chose concept images before an interactive implementation.

## Capabilities and Constraints

An effective calendar and to-do list must appear beside each other. The existing app is manual and desktop-first. Concept content is fictional; no live integrations or application changes are part of the image study.

## Brand Commitments

Use the supplied Notion and Obsidian screenshots as visual references: dark work surfaces, restrained navigation, generous reading space, and a personal page identity. These are references for this experiment, not a new production design system.

## Evidence on Hand

Two user-provided screenshots and the current React workspace implementation. Calendar and task content in the study is synthetic.
