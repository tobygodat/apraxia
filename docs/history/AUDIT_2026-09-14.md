# Codebase and app audit (2026-09-14)

> Historical record, moved to `docs/history/` on 2026-09-17. File names, counts, and sizes reflect the date it was written and are not maintained.

Scope: static review of `frontend/`, `api/`, `server/`, `shared/`, `supabase/`, `tests/`, docs and tooling, plus a Playwright click-through of the local QA workspace (all routes, add/search/edit dialogs, `dense`, `error`, `empty` scenarios, 400 px viewport). Measured baseline: `npm run build` 1 s; `vitest` 92 files / 1973 tests / 100 s; `tsc` clean for both frontend and server.

What is solid and should stay: RLS covers every table with column-scoped grants; every `SECURITY DEFINER` function pins `search_path = ''`; OAuth uses PKCE with hashed single-use state and AES-GCM token envelopes; the QA fixture does not leak into the production bundle; the UI has no console errors, no unlabeled controls, and no horizontal overflow at 400 px.

Items are ordered by payoff. Each has a one-line fix. "Effort" is S (< 1 h), M (half day), L (day+).

## 3. UI findings from the click-through

Screens are coherent and calm. These are the discrepancies seen:

- **Add-button style differs by page.** Projects, Ideas, and Media use a plain "Add project" pill inside a ~1050 px content column; Classes, Home, and Settings use a "+ Add class" button at the full 1404 px right edge. Pick one header pattern and one content max-width.
- **Two error styles in one view.** In the `error` scenario the calendar shows a square "Try again" button under plain text while the Tasks panel shows a red-bordered card with a pill "Try again". One error component.
- **Native `<select>` filters are unstyled** on the dark theme (Projects status, Media type/status) next to custom-styled inputs elsewhere.
- **Calendar overlaps become unreadable** at three or more concurrent events ("Diffe 9am", "Offic", "15 mint"). The `dense` scenario shows "Overlap" chips only. Consider a "+N more" collapse or minimum chip width with a tooltip.
- **The now-line pill ("3:23PM") sits on top of the "3 PM" hour label**; nudge it or hide the hour label when within 20 minutes.
- **Naming drift.** Sidebar and headings say "Tasks"; route, code, tables, and docs say "todos". Both appear in user-facing copy ("Add task" vs `/todos`).
- **Classes assignments table** uses a different gutter (349 px) from the page header (236 px), making the section look indented by accident.
- **Dialog footer buttons** are pills; page buttons are rounded rectangles. Choose one radius scale.

## 4. Documentation gaps

Ordered by how much they would help the next contributor.

1. **No architecture overview.** Nothing explains browser → RLS vs browser → `api/` → `server/` → Google, why `shared/` exists, or when code belongs in `frontend/src/api` vs `server/`. Add `docs/ARCHITECTURE.md` with one diagram and the placement rule.
2. **Data model documented for 2 of 7 domains.** Classes and Today have docs; todos, projects, ideas, media, collections, and the delete-undo token contract do not. Add `docs/WORKSPACE_DATA_MODEL.md`.
3. **README is a changelog.** Two-thirds is a dated "Verification record" that is already stale ("1,635 tests" vs 1973 today). Replace with a status line and links to feature docs.
4. **README and PRODUCT.md contradict each other on Drive.** README says the picker is implemented; PRODUCT says it is a placeholder. Code has a real picker. Fix PRODUCT.md.
5. **Env vars are undocumented as a set.** Eleven vars across two example files with validation rules only visible in `server/env/cloud.ts:37-45`. Add a table (name, required where, browser-safe, validation) to CLOUD_DEVELOPMENT.md. Rename `.env.example` to `.env.legacy.example`.
6. **QA fixture system is described in prose twice but never as a system.** No guide to adding a scenario or how `src/qa` services map to real services. One `docs/QA_FIXTURES.md`; README and AGENTS link to it.
7. **No conventions doc.** Folder layout, CSS approach (per-feature plain CSS with mixed BEM/kebab), testing approach (pgTAP vs PGlite vs happy-dom vs `tests/local`), and error-copy style are all unwritten.
8. **No ADRs** for the decisions the code clearly fought over: RLS-only browser access with the `orbitos_rpc` role, scalar page envelopes for Today, forward-only hosted migrations, Temporal on the server. Four short records in `docs/adr/`.
9. **DESIGN.md frontmatter names Georgia/Segoe UI while the app ships Space Grotesk and JetBrains Mono** (452 kB of TTFs). Reconcile.
10. **AGENTS.md carries a Windows-only absolute path** and PowerShell fences while development now happens on Linux/WSL. Use `git -c safe.directory="$(pwd)"` and bash fences.
